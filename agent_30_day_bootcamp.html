实践项目怎么用

不是并行做四个完整产品，而是把同一组 Agent 原语反复迁移。这样每次迁移都是一次“抽象是否正确”的测试。

工程权重排行榜

怎么理解权重

P0 / 4.8–5.0：不掌握就不要谈 Production。Agent Loop、Tool Design、Eval、Context、Reliability、Security。

P1 / 4.0–4.7：决定系统从 demo 变成可持续产品。MCP、Observability、Memory、Long-running、Skills/ACI、Orchestration。

P2 / <4.0：按场景学习。Multi-Agent、复杂 ToT/MCTS 等不应该占掉前两周。

如果某天时间不够：先完成 Build + Eval，再缩减阅读。这套计划把书当索引，不要求顺序通读。
