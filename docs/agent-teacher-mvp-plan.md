# Agent Teacher MVP 实施 Todo

## 目标

把现有两份课程网页升级为一个单人 Agent Engineering 私教：能够基于学习证据诊断能力、分派下一步任务、在线答疑、组织小测、分析薄弱项，并随课程资料更新知识。

## 产品边界

- 首版服务对象：一个已登录的学习者。
- 首版入口：Web，不接飞书、Telegram、Discord。
- `agent_30_day_bootcamp.html`：能力地图、练习和验收素材来源。
- `agent_30_day_bootcamp_v2.html`：唯一的默认教学路径与阶段划分来源。
- 30 天是默认节奏；任务由掌握证据和前置依赖动态调整，不按日期强制推进。

## P0：统一课程与能力模型

- [ ] 把 v2 的五阶段和 Day 1–30 节奏整理为结构化课程数据。
- [ ] 从基础划分页提取 18 个知识点、项目、阅读材料与验收要求。
- [ ] 为每个课程单元绑定：主题、前置主题、学习目标、阅读、练习、验收标准、资料来源。
- [ ] 解决两版阶段日期冲突：以 v2 为路径，原版只提供能力/练习/验收信息。
- [ ] 为每条资料保存 URL、发布或版本日期、抓取日期、可信等级和适用主题。

完成标准：系统可查询任一知识点的前置能力、相关课程单元、练习、验收要求和来源。

## P0：学习者状态与能力画像

- [ ] 创建学习者基础资料：目标、每周投入时间、时区、当前项目、偏好节奏。
- [ ] 创建 `competency_state`：主题、掌握度、置信度、最后评估时间、遗忘复习时间。
- [ ] 创建 `evidence`：作业提交、代码链接、笔记、对话回答、小测结果、教师反馈。
- [ ] 创建 `learning_task`：任务目标、关联主题、前置条件、状态、预期产出、验收 rubric。
- [ ] 以学习证据更新掌握度；禁止仅凭“已读/已打卡”判定掌握。

完成标准：系统能解释“为什么判断该主题薄弱”，并展示支撑该判断的证据。

## P0：教师 Agent 核心循环

- [ ] 定义教师 Agent 的结构化输出：`diagnosis`、`next_task`、`question`、`feedback`、`competency_updates`。
- [ ] 提供只读工具：课程检索、能力画像、最近证据、资料来源、当前任务。
- [ ] 提供受控写入工具：创建/调整任务、记录提交、记录评分、更新能力状态。
- [ ] 实现标准 tool-call 循环，保留每个 tool-use ID 并回传对应结果。
- [ ] 让答疑先分类：概念不清、前置缺失、实现路径、调试、范围过大；再选择追问、提示或示例。
- [ ] 让任务生成遵循“一个最小下一步 + 明确产出 + 可验收标准”。

完成标准：用户提交一次回答或作业后，Agent 能引用当前课程与历史证据给反馈，并生成下一步可执行任务。

## P1：评估与薄弱项分析

- [ ] 为主题建立题型：概念口试、情境选择、设计题、代码审查、trace 分析、项目验收。
- [ ] 为每题和每个作业建立 rubric，区分正确性、解释能力、工程权衡和可复现性。
- [ ] 实现小测会话：出题、接收答案、评分、追问、保存证据。
- [ ] 计算薄弱项：低分、重复错误、前置缺失、遗忘风险、任务长期卡住。
- [ ] 生成阶段报告：已掌握、待巩固、薄弱项、下一阶段建议。

完成标准：系统能在至少三个主题上用真实提交生成带证据的薄弱项报告，而不是只显示完成率。

## P1：Web 学习界面

- [ ] 首页显示：当前学习目标、今日任务、任务产出要求、验收标准。
- [ ] 增加提交入口：文本、笔记、代码片段、URL。
- [ ] 增加教师对话区，显示任务上下文和资料引用。
- [ ] 增加能力画像：主题掌握度、证据、薄弱原因、复习建议。
- [ ] 增加测验界面与阶段报告。
- [ ] 复用现有暗色主题；原始两份 HTML 作为只读“课程地图”入口。

完成标准：不使用命令行即可完成“领取任务 → 提交 → 获取反馈 → 小测 → 查看下一任务”的闭环。

## P2：知识更新与主动教学

- [ ] 建立资料录入流程：人工添加 URL 或受控抓取可信源。
- [ ] 保存摘要、原文片段、版本、主题映射和来源链接；新资料先标记为待审核。
- [ ] 课程回答显示引用及资料版本；资料冲突时提示而不混合断言。
- [ ] 实现复习提醒、停滞提醒和周计划；先在 Web 通知中心实现。
- [ ] 只在用户确认后接入一个外部消息渠道。

完成标准：新增一篇官方资料后，教师能够在相关答疑中检索并引用它，且不改变已确认课程的默认路径。

## 暂不做

- [ ] 多学生管理和管理员面板。
- [ ] 三渠道适配器并行接入。
- [ ] 自动执行不受信任的学生代码。
- [ ] 无来源、无审核的自动网页知识抓取。

## 推荐实施顺序

1. P0 课程模型与能力画像。
2. P0 教师 Agent 核心循环。
3. P1 评估和薄弱项分析。
4. P1 Web 闭环。
5. P2 知识更新和主动提醒。
