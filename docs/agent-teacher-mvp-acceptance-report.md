## 教师 Agent 验收

测试情境：用户说“我不会设计 Agent 的工具接口”。

- [ ] Agent 查询当前能力画像、相关课程与近期证据。
- [ ] Agent 不直接泛泛讲解，而是判断卡点并提出一个小问题或小任务。
- [ ] 任务包含明确产出和验收标准。
- [ ] Agent 的回复可显示相应课程或资料来源。
- [ ] 用户提交回答后，Agent 保存证据、给具体反馈并安排下一步。
